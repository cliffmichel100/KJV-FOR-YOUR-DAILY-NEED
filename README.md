# AkoSiBiko Bible Baptist Study Bible

A flat-file GitHub Pages website for a KJV-focused Bible study library.

## Upload

Put these files directly in the root of your GitHub repository:

- `index.html`
- `style.css`
- `app.js`
- `README.md`

No folders are required.

Enable **Settings → Pages → Deploy from a branch** and select the repository branch/root.

## What is included

- Realistic study-Bible / printed-page style interface
- 66-book KJV reader
- Chapter navigation
- KJV full-text search
- Random verse
- Original study notes
- Bible-Baptist doctrinal framework
- Salvation / church / evangelism / Christian-living indexes
- Theological glossary
- Bible geography and map resources
- Free/public-domain resource library
- Mobile-friendly layout
- Footer branding: **AKOSIBIKO**

## KJV source and copyright note

This site does not redistribute a commercial copyrighted study Bible.

The KJV reader obtains its machine-readable KJV corpus at runtime from an open repository/CDN. eBible.org identifies its KJV 1769 resource as public domain outside the UK, while Project Gutenberg identifies its KJV eBook as public domain in the USA. Copyright and Crown Copyright rules can vary by jurisdiction, so users should check local law before redistributing the text.

The interface and original notes in this project are newly written for this site.
